# 大会予約デモ (reservation-event-demo)

スポーツ大会のエントリー受付を想定したLINE予約デモ。**LIFFアプリとして設置するプレゼン用デモ**です。

- **大会選択 → 入力 → 確認 → 完了** の4ステップ（カレンダー選択なし）
- 大会ごとに出場枠（チーム数）を持ち、**枠が埋まった大会はキャンセル待ち予約**になる
- 入力項目はチーム名・代表者名・代表連絡先（電話番号）
- **LIFFログイン**: デモを見る相手のLINEプロフィールを取得して表示
- **申込控え送信**: Messaging API で受付確認をLINEに送信（キャンセル待ちの場合はその旨も記載）
- **DB保存なし**: データは閲覧者の端末の localStorage にのみ保存

## ローカルでの起動（LINE設定なし）

```bash
npm install
npm run dev
```

`VITE_LIFF_ID` 未設定の場合はダミーユーザー（山田 花子）で自動ログインし、LINE通知はスキップされます。

| 画面 | URL |
|------|-----|
| エントリー画面（参加者用） | http://localhost:5173/ |
| 管理画面 | http://localhost:5173/admin （パスワード: `demo`） |

## キャンセル待ちの仕様

- 大会選択画面で満員の大会には「満員（キャンセル待ちのみ）」バッジと注記を表示
- 入力・確認画面に警告バナー「キャンセル待ちでの予約となります」を表示
- 確定ボタンは「キャンセル待ちで予約する」に変わる
- 完了画面・LINE申込控えにもキャンセル待ちである旨を明記（待ち順位は表示しない）
- 管理画面で本予約をキャンセルすると、**キャンセル待ちの先頭が自動で本予約に繰り上がる**

## 初期データ（初回アクセス時に自動生成）

| 大会 | 出場枠 | 申込済 | 状態 |
|------|--------|--------|------|
| 第12回 サマーカップ | 16 | 6 | 受付中 |
| ビーチボールバレー交流大会 | 8 | 8 | **満員 → キャンセル待ちデモ用** |
| ナイターカップ | 10 | 3 | 受付中 |
| 秋季リーグ 開幕戦 | 12 | 11 | 残り1枠（満員になる瞬間をデモできる） |

管理画面下部の「デモデータをリセット」で初期状態に戻せます。

## 管理画面の機能

- **エントリー一覧**: 大会別に本予約（番号付き）とキャンセル待ち（申込順）を表示。
  キャンセル処理で繰り上げを実演できる
- **大会管理**: 大会の追加・編集・削除・公開切替（大会名・開催日・会場・出場枠・説明）

## LIFFアプリとして設置する手順

1. [LINE Developers](https://developers.line.biz/) でプロバイダー＋Messaging APIチャネルを作成
2. LIFFアプリを追加（エンドポイントURL = VercelのデプロイURL、スコープ: `profile`）
3. Vercel にデプロイし、環境変数を設定:
   - `VITE_LIFF_ID` — LIFFアプリのID
   - `LINE_CHANNEL_ACCESS_TOKEN` — Messaging API のチャネルアクセストークン
   - `ADMIN_LINE_USER_ID` — （任意）デモ申込の通知を受け取る自分のLINEユーザーID
4. LIFF URL を相手にLINEで送れば、LINE内でデモが開きます

※ プッシュ送信には相手がチャネルの公式アカウントを友だち追加している必要があります。
※ DBがないため、相手の端末で入れたエントリーは自分のPCの管理画面には表示されません。
